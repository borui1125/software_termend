管院小幫手

管理學院整合服務平台

請選擇下方功能模組（進入模組前需先完成帳號登入）

MODULE 01 · 空間導覽

管院空間與設備查詢

瀏覽各樓層平面圖、教室容納人數、投影與電腦設備清單及 360 度環景照片。

MODULE 02 · 預約申請

空間與物品預約借用

線上申請借用研討室、教室鑰匙、無線投影筆與筆記型電腦，即時追蹤審核進度。

MODULE 03 · 課程排程

課程時間與志願排課

查詢各教室學期課表使用時段；教師可登記排課志願時段並由管理員協調排定。

ADMIN · 系統管理

帳號審核與權限管理

審核新註冊的使用者帳號申請、指派教師或管理員角色權限，維護系統資料安全。
